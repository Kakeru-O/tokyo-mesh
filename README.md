# Tokyo Mesh Insight AI 🗼

Tokyo Mesh Insight AI は、東京都の地域メッシュ統計（人口、属性データなど）を可視化し、AIエージェントがその地域の特性を分析・解説するアプリです。

## 🗺️ 地域メッシュとは
地域メッシュ（標準地域メッシュ）は、日本全国を緯度・経度に基づいて格子状に区切った単位です。
- **特徴**: 行政区分（市区町村など）に依存せず、常に一定の形状で統計情報を管理できるため、エリアごとの正確な比較や時系列分析に適しています。
- **階層**: 第1次メッシュ（約80km四方）から第6次メッシュ（約125m四方）まで定義されており、本アプリではこれらを動的に切り替えて表示します。

## ✨ 主な機能
- **インタラクティブ・メッシュマップ**:
  - 第1次～第6次（125mメッシュ）までの統計データを地図上に可視化。
  - 性別、年代別のフィルタリングによる動的なヒートマップ表示。
  - Pydeckによる高度な地理空間レンダリング。
- **統計分析チャート**:
  - 選択エリアの性年代別人口ピラミッド（Plotly）を表示。
  - 平均年齢やフィルタリング後の人口総数などのメトリクス算出。
- **AIアシスタント (The Analyst)**:
  - 地図上のデータについて自然言語で質問可能。
  - 「〇〇駅周辺の30代の人口は？」「このエリアの特徴を教えて」といった問いに対し、AIが統計データを解析して回答。

## 🤖 AI機能（Google AI Studio 対応）
本アプリのAI機能は **Google Gemini (Google AI Studio)** を利用しています。

### 利用方法
1. [Google AI Studio](https://aistudio.google.com/) でAPIキーを取得します。
2. アプリ起動後、サイドバーの「🤖 AI設定」セクションにある「Google AI API Key」欄に取得したキーを入力してください。
3. デフォルトで `gemini-2.5-flash` などの最新モデルが選択可能です。

### 技術スタック
- **AIフレームワーク**: [Google Agent Development Kit (ADK)](https://github.com/google/adk)
- **モデル**: Gemini 2.5 Flash / Flash-Lite / 3-Flash (対応予定含む)

## 🛠️ ローカルでの動かし方
本プロジェクトは Python パッケージマネージャーの `uv` を使用して構築されています。

### 1. 前提条件
- Python 3.12 以上
- [uv](https://github.com/astral-sh/uv) がインストールされていること

### 2. セットアップ
以下のコマンドでリポジトリのクローンと依存関係のインストールを行います。

```bash
# リポジトリのクローン
git clone https://github.com/Kakeru-O/tokyo-mesh.git
cd tokyo-mesh

# 依存関係のインストール
uv sync
```

### 3. アプリの起動
```bash
# Streamlitの起動
uv run streamlit run app.py
```

起動後、表示されたURLにブラウザでアクセスしてください。

## 📊 使用データ

- **項目**: 総人口、男女別・年代別人口、平均年齢など
